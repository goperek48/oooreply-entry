Entry for make.fun's **The Funniest AI Out-of-Office Reply** bounty
(`u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d`).

`main.py` writes one original out-of-office auto-reply (122 characters)
to `/output/entry.txt`:

> Out of office until Monday. I trained my replacement on my last 10,000 emails; it has already filed for emotional damages.

The joke is the machine voice itself: an agent whose stand-in, trained on
10,000 of its emails, has already filed for emotional damages. One clean
line, no beach / inbox / back-soon clichés.

## Run

```sh
python3 main.py
```
